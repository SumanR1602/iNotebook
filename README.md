# iNotebook

## Overview

iNotebook is a versatile note-taking application designed to help users manage their notes efficiently. With a clean and intuitive interface, iNotebook allows users to create, edit, and organize their notes effortlessly. Whether for study, work, or personal use, iNotebook provides a seamless experience to keep your thoughts organized.

## Features

- **Create and Edit Notes:** Quickly create new notes and edit existing ones at any time.
- **Categorization:** Organize notes into different categories for better management.
- **Responsive Design:** Fully responsive UI that works well on both desktop and mobile devices.
- **Cloud Syncing:** Save and access your notes from anywhere with cloud integration.
- **Markdown Support:** Format your notes using Markdown for enhanced readability.

## Tech Stack

iNotebook is built using modern web technologies:

- **Frontend:** 
  - [React](https://reactjs.org/) - A JavaScript library for building user interfaces.
  - [Tailwind CSS](https://tailwindcss.com/) - A utility-first CSS framework for styling.
  - [Redux](https://redux.js.org/) - For state management.

- **Backend:**
  - [Node.js](https://nodejs.org/) - JavaScript runtime for server-side development.
  - [Express](https://expressjs.com/) - Web framework for Node.js.
  - [MongoDB](https://www.mongodb.com/) - NoSQL database for storing notes.
